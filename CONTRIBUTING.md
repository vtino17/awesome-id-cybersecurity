# Contributing

1. Fork repository ini
2. Tambah resource ke README.md sesuai kategori
3. Pastikan urutan alphabetical
4. Buat Pull Request dengan deskripsi perubahan

## Guidelines

- Resource harus relevan untuk cybersecurity Indonesia
- Link harus aktif dan dapat diakses publik
- Tambah deskripsi singkat (1 baris)
- Hindari link afiliasi atau konten berbayar
